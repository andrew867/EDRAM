# Nortel EDRAM converter

Address-aware extraction of DMS-100 and SL-100 EDRAM announcements from binary G-record and Motorola S-record load files.

The verified converter, format notes, tests, original load files and extracted WAV corpus are being imported in the following commit. Default audio expansion follows Joe Z's unmasked A-law method. Direct listening and hardware-equivalent tone playback remain separate validation items.

Prior work and sample archive: http://www.dms-100.net/telephony/nortel/dms-100/edram/
